# Dominio lucagalati.com su Cloudflare Registrar, hosting GitHub Pages

Serve un indirizzo stabile per decenni (link in paper, CV, SSRN, Scholar) al costo minimo. Scelto `lucagalati.com` comprato a prezzo di costo su Cloudflare Registrar (DNS Cloudflare), servito gratis da GitHub Pages dal repo utente `LucaGalati.github.io` con file `CNAME`; `lucagalati.github.io` resta come redirect automatico. Scartati: solo `lucagalati.github.io` (gratis, ma indirizzo legato a GitHub e allo username), Cloudflare Pages (obbliga a riscrivere il deploy GitHub Actions della spec King), `.eu`/`.de` (più economici ma legati alla residenza).
